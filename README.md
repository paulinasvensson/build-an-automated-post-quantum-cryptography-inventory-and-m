# PQC Crypto Inventory Scanner

A developer-focused tool that discovers quantum-vulnerable cryptography (RSA,
ECC/ECDSA/ECDH, DH, DES/3DES, MD5, SHA-1, RC4) in pasted source code, TLS
config, or dependency manifests, and generates a prioritized migration
roadmap to NIST-approved post-quantum algorithms (ML-KEM/Kyber,
ML-DSA/Dilithium, SLH-DSA/SPHINCS+).
